## Code and build
- src/native-lottie.h/.cpp: synchronous native CPU renderer, premultiplied ARGB -> little-endian BGRA, bounded one-DPI lazy cache, balanced ThorVG ownership. A real DPI regression (paint cannot move to another renderer) was fixed by retargeting the same canvas, preserving animation ownership. Tests cover 16 -> 32 -> 64 -> 16.
- src/lottie-playback.h: authored segments map to frame10 check, 300ms reveal /1500ms held check /300ms return, repeated copy extends/resumes; refresh 500ms loops only after successful Reload and until actual navigation completion. Completion finishes current loop before resting; five-second animation cap prevents indefinite autonomous motion. Copy dwell uses a deadline, no frame ticks. Reduced motion uses static PNG/opacity-only feedback and no Lottie frame ticks or press scale.
- src/main.cpp: shared one-shot timer combines existing motion with Lottie deadlines, successful SetClipboardData is the sole copy trigger, successful Reload and NavigationCompleted control refresh, tab selection/error/minimize lifecycle integrated. Downloads untouched.
- src/chrome.h: JSON bitmap composited at exactly .5*iconOpacity to match static Phosphor PNGs; existing single hover/press surface retained. Missing/invalid JSON falls back to static Phosphor. Uses every peer TabStrip geometry helper; close uses right-28..right-4, title right-32, tab pitch134, tab/plus gap6. Focus exactly white10%, stroke1DIP/inset.5. Deleted legacy Surface::focus after peer completion allowed it. Existing favicon and horizontal-only ellipsis behavior preserved.
- build-lottie.py fetches/verifies source SHA256 03850904c300e5969560d49446eab3e534c4160c379909f32bc49a32ea6f4072 and builds with project-local Meson1.9.1/Ninja1.13.0. No global install/PATH/security changes. CPU+lottie+svg only, no JS expressions, threads, GPU, image/font loaders or file IO. Local GCC lacks LTO; explicitly disabled. third_party/thorvg contains ThorVG and RapidJSON licenses and reproduction notes.
- build.ps1 and all three existing native UI fixture scripts link production adapter/static library. test-design-system.ps1 default now build/lottie-polish/design-system to protect existing preview. test-lottie.py reproduces five native fixtures.
