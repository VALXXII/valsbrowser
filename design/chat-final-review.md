Lecture seule : aucun fichier source modifié, aucun navigateur ni vraie fenêtre lancés, rien n'a été exécuté. Tout ce qui suit vient de la lecture du code ; chaque défaut porte un niveau de confiance :

- **sûr** : le chemin se lit de bout en bout dans le code ;
- **probable** : le chemin se lit, mais l'effet à l'écran dépend du rendu réel (à confirmer par Q en vraie fenêtre).

État relu : arbre de travail du worktree `annotations-chat` après `5647e2a`, pendant que H1 modifiait `chat-comment.h`, `chat-bubble.h`, `chat-host*.h`, `chat-options.h`. Les numéros de ligne sont ceux de l'arbre au moment de l'écriture ; le nom de la fonction est toujours donné pour retrouver l'endroit s'ils ont bougé.
