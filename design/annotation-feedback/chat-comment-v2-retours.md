# Mode Commentaire — retours du premier test réel (18 novembre 2026, soir)

Test de l'utilisateur sur `landing.html` avec un vrai Claude Code (Opus 5.5 · Moyen), build `build/chat-preview` (commits f7a3247, 3a63813, feac9dc, e50c8ee, 9f1aea1).

**Exigence n° 1 de l'utilisateur : le code doit être exactement le design Paper.** Pas « proche », pas « inspiré » : mêmes rayons, tailles, espacements, couleurs, typographies, positions, comportements. Toute différence non listée ici comme décision est un défaut. Source de vérité : fichier Paper `01M6Q7YT14ZKMGET54ASPNGQEC`, planches listées dans `chat-comment-mode-brief.md` (et 6.4 `14P2-0` pour les menus, 5.2 `11CY-0` / bandeau `1AYH-0` pour le masque). Lire les valeurs avec `get_computed_styles` / `get_jsx`, jamais sur une capture.

## Qualité
Skills obligatoires : `<Bureau>/skills/` (apple-design, emil-design-eng, better-ui, better-interface, better-layout, better-typography, better-colors, better-accessibility, better-writing). Captures en vraie fenêtre de chaque état, mises **côte à côte avec la capture Paper** de la planche, et tableau d'écarts mesurés (valeurs calculées dans le DOM vs valeurs Paper). Zéro écart non justifié avant de rendre.

## Sécurité (inchangé)
Jamais de modification des vraies configs Claude/Codex. Tests avec APPDATA/USERPROFILE/CODEX_HOME/PATH redirigés, `BROWSER_ANNOTATIONS_TEST=1`, faux agent seulement. L'utilisateur a peut-être encore `build/chat-preview` ouvert : ne pas le fermer ; construire ailleurs (`build/chat-comment-v2`) jusqu'au feu vert. Parcours en vraie fenêtre seulement après le message « Libre » du coordinateur. Pas de push, pas de fusion.
